## 关于我

在现实我是一个比较内向的人，在网上，可能社恐一些，但是很想和大家聊的开，虽然会别人的一句话让我胡思乱想，常常会后悔...

我的爱好？我似乎没有真正的爱好，我在想我的爱好是什么的时候感觉到了绝望。开服务器？coding？玩游戏？我真的要的是这些吗...

我是否该说我很自卑，说自己自卑感觉会被别人认成嘉豪？乐子？我就这么点用也确实应该自卑不是吗，我也许是同龄人中最认同自卑使人进步这句话的人了，但是再怎么样的自卑还是撑起不了身体的惰性？我很懒惰吗？我似乎也没有特别懒惰，但就是很多事我没有去做，也就是我没有走出自己的舒适圈，我该如何走出舒适圈呢？oh 逃避问题是我的缺点，或许有时候会变成优点，但是不要用在这种地方啊喂！

我似乎不是很善良，窝在自己的舒适圈里对其他人造成过不少伤害...特别是家人吧...但是似乎自己做的没错，也许我当时不反抗我绝不会在这里和大家畅谈，但无可否认的是我对家人造成了伤害，家人是爱我的，也许我必须冲出鸟笼才能呼吸？也许只是我太笨了，太懒了没有在学业方面有很大的造诣？也许是吧。真的是吗？

我似乎在反思了，我似乎是在向善的......天哪...我在说什么？...我应该自洽吧，应该吧。

高一了，我在怀念初三，怀念那段忙碌的日子，似乎有人看管的时候也没什么不好的，也许只是自由带给我的陌生感和不熟悉的环境让我感到恐惧。

## 第一个仓库

初三下学期，辅导课以后的夜晚能拿出时间搞电脑，在那时多是一件美事啊。我还记得，我的一个大学生老师，看我比较懂AI想向我学学，晚上老师快走时，老师和我一起坐电脑前面打开 OpenAI 官网，结果被归途跳脸...

白天我会计划好晚上干什么和记下白天想好的好点子

我的第一个仓库就是在那时做的，是为一个群友做的，也许只算是受到他的启发？和我同龄，苦恼于每天背单词，我突发奇想，是否可以在服务器中做一个强制你背单词的插件呢（当然，现在不强制了）？于是就有了 [Let-s-learn-English](https://github.com/sqkl520/Minecraft-server-plugin-Let-s-learn-English)，它有着很舒适的箱子 GUI 界面，强迫症看起来很舒服。我当时在群里面提起过，不过也没大有人关注，很难想象当时一个小小的念头做出了成果，现在，2 star——不管旁人是否在意，不管现实里的人是否在意，我都很有成就感

很可惜，我一行代码都没有写，vibe coding 出来的玩意。我似乎又因此而自卑，

很悲哀，人类的自我价值在这一刻贬值了。在此之前，想法转换成实物在以前需要长久的努力，现在说一句话的事，这其中又牵扯到经济实力，增加了普通人的门槛。现在，说不定明天我的想法就被别人捷足先登，这种概率会越来越大，我们还有什么价值？一切事情变得功利的时候都感觉失去了意义...

但创造意义又常常发生在过程里：我白天记下想法，晚上研究，那个“多是一件美事”的夜晚本身就有价值。它不是手段，它就是我生活的一部分。虽然这很鸡汤，但这似乎就是我们普通人对抗AI浪潮、对抗宇宙终将覆灭这种既定事实——最好的方式。也许过程才是最重要的呢？

享受创造的过程吧，万一成了呢？也许，结果真的不重要...
